# A股筛选器 — 功能扩展需求

> 日期: 2026-05-26
> 版本: v1.0
> 状态: 已确认

## 一、背景

当前筛选器（MQ1）仅支持按涨跌幅/成交量/ST 筛选并排序。现扩展为基础股票分析工具，补充股票浏览、K线分析、市场统计等高频功能。

所有数据基于 hikyuu HDF5 + SQLite，前端 Streamlit，端口 8082。

## 二、新增功能清单

### 2.1 股票详情页

| 项 | 说明 |
|----|------|
| 入口 | 筛选结果表格中点击股票代码，或顶部搜索框输入 |
| 展示 | 股票名称/代码/市场 + 最新价/涨跌幅/成交量 |
| K线图 | 交互式日K（可缩放、拖拽），下方成交量柱 |
| 均线叠加 | 勾选 MA5/MA10/MA20/MA60，可多选 |
| 数据范围 | 默认近 120 日，可调 |

### 2.2 市场统计

| 项 | 说明 |
|----|------|
| 指数行情 | 上证指数、深证成指、沪深300 实时走势小卡片 |
| 涨幅榜 | 全市场涨幅 Top 10，默认排除 ST |
| 跌幅榜 | 全市场跌幅 Top 10，默认排除 ST |
| 成交量榜 | 全市场成交量 Top 10 |
| 涨跌分布 | 当日涨跌家数统计 + 柱状图 |

### 2.3 板块筛选

| 项 | 说明 |
|----|------|
| 行业筛选 | 下拉选择行业板块（保险/银行/半导体/...共 86 个） |
| 概念筛选 | 下拉选择概念板块（435 个） |
| 与现有筛选联动 | 行业/概念筛选后，再叠加涨跌幅/成交量等条件 |

### 2.4 股票搜索

| 项 | 说明 |
|----|------|
| 模糊搜索 | 输入代码或名称片段，实时匹配 |
| 结果展示 | 代码 + 名称 + 最新价，点击进入详情页 |

### 2.5 仪表盘首页

| 项 | 说明 |
|----|------|
| 大盘概览 | 四大指数卡片（上证/深证/沪深300/创业板）|
| 涨跌统计 | 今日涨跌平家数 + 涨幅分布 |
| 热门板块 | 行业板块涨跌 Top 5 |
| 入口 | 顶部导航：筛选器 / 股票详情 / 市场统计 |

## 三、技术实现

### 3.1 数据层（复用）

```
screener/hikyuu_adapter.py  — 已有，单例导入
screener/engine.py          — 已有，screen() 函数
```

### 3.2 新增模块

```
screener/
├── details.py       股票详情（K线图 + 均线 + 指标）
├── stats.py         市场统计（涨跌分布/排名/指数）
├── blocks.py        板块查询（hikyuu Block 封装）
├── search.py        股票搜索
└── app.py           主入口（多页面路由）
```

### 3.3 页面路由方案

Streamlit 的 `st.navigation()` + `st.Page()` 多页面：

```
app.py (入口)
├── pages/
│   ├── 01_筛选器.py     — 现有筛选器
│   ├── 02_股票详情.py   — 单只股票 K 线分析
│   └── 03_市场统计.py   — 大盘概览
```

### 3.4 K 线图方案

**Plotly**（替代 matplotlib）。交互式缩放/拖拽，支持均线叠加，效果好于 matplotlib 静态图。

```bash
pip install plotly
```

或直接用 hikyuu 的 `k.plot()`（matplotlib 后端，支持均线但不够交互）。

## 四、交付物

| 交付物 | 路径 | 说明 |
|--------|------|------|
| 详情模块 | `screener/details.py` | 单只股票 K 线 + 均线 |
| 统计模块 | `screener/stats.py` | 涨幅榜/成交量榜/分布 |
| 板块模块 | `screener/blocks.py` | 行业/概念查询 |
| 搜索模块 | `screener/search.py` | 模糊搜索 |
| 多页面应用 | `screener/app.py` + `pages/` | 导航路由 |
| 需求文档 | `docs/11-screener-features.md` | 本文档 |

## 五、价值

| 能做的 | 不能做的 |
|--------|---------|
| ✅ 查任意股票 K 线 + 均线 | ❌ 暂不支持 MACD/RSI 等副图指标 |
| ✅ 全市场涨幅榜/成交量榜 | ❌ 不是实时行情（盘后更新） |
| ✅ 按行业/概念筛选 | ❌ 不支持板块热力图 |
| ✅ 代码模糊搜索 | ❌ 不支持自选股收藏 |
| ✅ 大盘指数一览 | ❌ 不支持分时图（仅日线） |

## 六、优先级

```
P0（本轮）:
  - 股票详情页（K线 + 均线）
  - 市场统计（指数 + 涨跌榜）
  - 股票搜索

P1（下轮）:
  - 板块筛选
  - 仪表盘首页

P2（后续）:
  - K线叠加 MACD/RSI/KDJ
  - 自选股收藏
  - 板块热力图
```
