## 十、P2 技术设计

### 10.1 K线叠加技术指标

在股票详情页（`pages/02_股票详情.py`）的 K 线图下方，新增指标副图。

#### 页面布局

```
┌─ K 线图（已有）─┐
├─ 指标选择 ──────┤  ← 新增：勾选 MACD / RSI / KDJ
├─ 指标副图 ──────┤  ← 新增：Plotly subplot
└─────────────────┘
```

#### 指标实现

| 指标 | 计算方式 | 副图内容 |
|------|---------|---------|
| MACD | hikyuu `MACD(close)` / pandas 计算 | DIF 线 + DEA 线 + 柱状图 |
| RSI | hikyuu `RSI(close, n=14)` / pandas 计算 | RSI 线 + 30/70 参考线 |
| KDJ | hikyuu `KDJ(k)` 或 pandas 计算 | K 线 + D 线 + J 线 + 20/80 参考线 |

计算方式优先用 hikyuu indicator，因为数据已在内存中预热（0.37s 加载）。减少重复计算。

#### 文件变更

| 文件 | 操作 | 说明 |
|------|------|------|
| `screener/details.py` | 修改 | 新增 `plot_indicators()`，K线图下追加指标副图 |
| `screener/pages/02_股票详情.py` | 修改 | 新增指标多选，调用 `plot_indicators()` |

### 10.2 自选股收藏

#### 数据存储

本地 SQLite 文件 `~/.quant-favorites.db`，一张表：

```sql
CREATE TABLE favorites (
    code TEXT PRIMARY KEY,    -- 'SZ000001'
    name TEXT,                -- '平安银行'
    added_at TEXT             -- '2026-05-26 18:00:00'
);
```

#### 页面功能

在导航栏新增「⭐ 自选股」页面，提供：

| 功能 | 说明 |
|------|------|
| 添加自选 | 搜索框 + 添加按钮，或从详情页点击 ⭐ 加入 |
| 自选列表 | 表格显示：代码/名称/最新价/涨跌幅/成交量 |
| 移除自选 | 每行一个 ❌ 按钮 |
| 导出 | CSV 导出 |

#### 新增模块

| 文件 | 操作 | 说明 |

| `screener/favorites.py` | 新增 | SQLite 读写 + CRUD |

### 10.3 板块热力图

#### 展示形式

在仪表盘页或市场统计页，用 Plotly Treemap 展示行业板块热力图。

| 元素 | 说明 |
|------|------|
| 矩形大小 | 板块股票数量 |
| 颜色深浅 | 板块平均涨跌幅（红涨绿跌） |
| 悬停信息 | 板块名 / 平均涨幅 / 上涨家数 / 下跌家数 |

| 文件 | 操作 | 说明 |
