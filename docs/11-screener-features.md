# A股筛选器 — 功能扩展需求

> 日期: 2026-05-26
> 版本: v1.1
> 状态: P0 已交付，P1 待确认

## 一、背景

当前筛选器已支持股票详情（K线+均线）、市场统计（指数+涨跌榜）、股票搜索。本轮（P1）新增板块筛选和仪表盘首页。

所有数据基于 hikyuu HDF5 + SQLite，前端 Streamlit，端口 8082。

## 二、新增功能清单

### 2.1 股票详情页

| 项 | 说明 |
|----|------|
| 入口 | 筛选结果表格中点击股票代码，或顶部搜索框输入 |
| 展示 | 股票名称/代码/市场 + 最新价/涨跌幅/成交量 |
| K线图 | 交互式日K（可缩放、拖拽），下方成交量柱 |
| 均线叠加 | 勾选 MA5/MA10/MA20/MA60，可多选 |
| 数据范围 | 默认近 120 日，可调 |

### 2.2 市场统计

| 项 | 说明 |
|----|------|
| 指数行情 | 上证指数、深证成指、沪深300 实时走势小卡片 |
| 涨幅榜 | 全市场涨幅 Top 10，默认排除 ST |
| 跌幅榜 | 全市场跌幅 Top 10，默认排除 ST |
| 成交量榜 | 全市场成交量 Top 10 |
| 涨跌分布 | 当日涨跌家数统计 + 柱状图 |

### 2.3 板块筛选

| 项 | 说明 |
|----|------|
| 行业筛选 | 下拉选择行业板块（保险/银行/半导体/...共 86 个） |
| 概念筛选 | 下拉选择概念板块（435 个） |
| 与现有筛选联动 | 行业/概念筛选后，再叠加涨跌幅/成交量等条件 |

### 2.4 股票搜索

| 项 | 说明 |
|----|------|
| 模糊搜索 | 输入代码或名称片段，实时匹配 |
| 结果展示 | 代码 + 名称 + 最新价，点击进入详情页 |

### 2.5 仪表盘首页

| 项 | 说明 |
|----|------|
| 大盘概览 | 四大指数卡片（上证/深证/沪深300/创业板）|
| 涨跌统计 | 今日涨跌平家数 + 涨幅分布 |
| 热门板块 | 行业板块涨跌 Top 5 |
| 入口 | 顶部导航：筛选器 / 股票详情 / 市场统计 |

## 七、P1 技术设计

### 7.1 板块筛选

#### 数据来源

hikyuu 板块系统：739 个板块（行业 86 / 概念 435 / 指数 187 / 地域 31）。

```python
blocks = sm.get_block_list()
# b.category: '行业板块' | '概念板块' | '指数板块' | '地域板块'
# b.name: '保险' | '半导体' | ...
# 遍历 b 获取板块内股票: for s in b: ...
```

#### 与现有筛选器集成

在筛选器页面（`pages/01_筛选器.py`）新增两个下拉框：

| 控件 | 说明 |
|------|------|
| 行业板块下拉 | 二级下拉：先选板块分类（行业/概念），再选具体板块 |
| 联动逻辑 | 选择板块后缩小候选池：只从该板块股票中筛选 |

#### engine 函数签名变更

`screen()` 新增参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| block_category | str 或 None | None | 板块分类。'行业板块' / '概念板块' |
| block_name | str 或 None | None | 板块名称。'半导体' / '保险' |

当指定板块时，`_get_candidates()` 改为从板块取股票而非全市场遍历。

### 7.2 仪表盘首页（页面 4）

新建 `pages/04_仪表盘.py`，作为默认首页。

#### 页面布局（3 行）

| 区域 | 内容 |
|------|------|
| 顶部：数据时间 | 页面标题下方显示「📅 数据日期: YYYY-MM-DD」（从 hikyuu 取最新交易日） |
| 第 1 行：指数卡片 | 4 个 st.metric：上证指数 / 深证成指 / 沪深300 / 创业板指，每个卡片内显示涨跌幅 |
| 第 2 行：涨跌统计 | 涨/跌/平 家数 + 柱子图，标题标注统计日期 |
| 第 3 行：热门板块 | 行业板块按涨跌幅排序 Top N（默认 10，可调），点击板块名展开板块内股票明细 |

#### 板块明细展开

点击热门板块名称后展开子表格，显示：

| 列 | 说明 |
|----|------|
| 代码 | 股票代码 |
| 名称 | 股票名称 |
| 最新价 | 最新收盘价 |
| 涨跌幅 | 当日涨跌幅 |
| 成交量 | 当日成交量 |

子表格按涨跌幅降序排列，支持导出。

#### 板块 Top N 可配置

`get_top_blocks(n)` 默认 n=10（改为可配置），仪表盘页面提供 slider 控件。

#### 数据函数（均复用已有）

| 功能 | 已有函数 |
|------|---------|
| 指数行情 | `stats.get_all_index_cards()` + `stats.get_index_card("创业板指")` |
| 涨跌分布 | `stats.get_up_down_stats()` |
| 热门板块 | 新增 `blocks.get_top_blocks(n=5)` |

#### 实现

新增 `screener/blocks.py`，提供：

| 函数 | 签名 | 说明 |
|------|------|------|
| get_block_list | `(category: str) -> list[dict]` | 返回某分类下所有板块名 + 股票数 |
| get_block_stocks | `(category: str, name: str) -> list` | 返回板块内股票列表（hikyuu Stock 对象） |
| get_top_blocks | `(n: int=10) -> list[dict]` | 行业板块涨幅 Top N（默认 10） |
| get_block_stock_details | `(category, name) -> list[dict]` | 板块内每只股票详情（代码/名称/最新价/涨跌幅/成交量） |
