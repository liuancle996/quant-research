# 因子实验室 — Streamlit 前端页面需求

> 日期: 2026-05-27
> 版本: v0.1 草案
> 状态: 待确认

## 一、背景

`factor_lab/` CLI 引擎已交付（doc/12），支持命令行因子评估。现在需要 Web 前端，让用户在页面上选因子 + 调参数 → 跑分析 → 看可视化结果。

## 二、定位

在现有 Streamlit 筛选器（端口 8082）上新增第 6 个页面，默认用沪深 300（277 只，< 5s），可切换到全量 A 股。

### 3.1 左侧控件

| 控件 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 因子类型 | selectbox | momentum | momentum / volatility / price_position / volume_ratio |
| 参数 n | number_input | 20 | 因子参数 |
| 前向天数 | number_input | 20 | forward days |
| 股票池 | radio | 沪深300 | 沪深300 / 全量A股 |
| Z-score 标准化 | checkbox | ☐ | `--normalize zscore` |
| 运行按钮 | button | — | 触发分析 |

### 3.2 右侧结果

| 区域 | 内容 | 图表类型 |
|------|------|----------|
| 指标卡片 | IC 均值、IC IR、IC>0 占比、平均覆盖率 | st.metric × 4 |
| IC 序列 | 每日 IC 折线图 | plotly line chart |
| IC 衰减 | forward 1/5/10/20/30/60 天 IC 均值 | plotly bar chart |
| 分层收益 | Q1-Q5 分组平均收益 | plotly bar chart（正收益绿、负收益红） |
| 排名表格 | Top 20 / Bottom 20（代码 + 名称 + 因子值） | st.dataframe × 2 |

## 四、技术要点

### 4.1 沪深 300 股票获取

```python
hs300 = sm.get_block("指数板块", "沪深300")
stocks = list(hs300)  # 277 只
```

### 4.2 性能

沪深 300 默认模式：`build_mf` + `extract_scores` + 缓存 forward returns → < 5s。用户点击按钮后显示 spinner，5s 内出结果。

全量 A 股模式首次 60s，需提示用户等待。

### 4.3 缓存复用

与 CLI 共享同一 `factor_lab/cache/` 目录。前端调用 `get_or_compute_forward_returns()` 自动命中缓存。

### 4.4 session_state

分析结果存 `st.session_state`，避免切换控件时丢失。只有当用户点击"运行分析"按钮时才重新计算。

### 4.5 文件位置

```
screener/pages/06_因子实验室.py
```

在 `screener/app.py` 中注册为新页面。

## 六、价值

### 做完了能做什么

- 在浏览器上选因子、调参数，5s 内看到 IC/分层/衰减可视化结果
- 不需要记 CLI 命令，不需要切终端
- 快速对比不同因子的表现（切因子类型 → 点运行 → 5s 出结果）

### 做完了不能做什么

- 不能做策略回测（需 P1）
- 不能做多因子组合
- 不能导出报告 PDF/HTML（后续迭代）
