## 一、定位与目标

### 1.1 一句话定位

**一个私有的、随身的金融量化 + AI 技术知识库，嵌入日常开发与研究流程，让 AI 辅助不降智。**

### 1.2 核心目标

| 目标 | 现状痛点 | 期望效果 |
|------|---------|---------|
| 提升工作效率 | 每次查 API 从零搜索、代码片段散落各处 | 自然语言一问即得，附带可运行代码 |
| 深耕量化行业 | 论文/研报读完就忘，策略思路无法沉淀 | 知识积累可检索、可关联、可复用 |
| AI/Agent 前沿追踪 | ArXiv/博客信息过载，筛选成本高 | 自动摘要 + 分类，按需检索 |
| 降低重复劳动 | 同样的 bug 踩多次，同样的配置反复查 | 错误→修复自动录入，下次自动提醒 |

## 五、技术实现细节

### 5.1 文档处理 Pipeline

```
原始文档
  │
  ├── *.md          → Markdown 解析 → 按 ## 标题切片
  ├── *.ipynb       → nbconvert → Markdown → 同上
  ├── *.py (注释)   → AST 解析 → 提取 docstring + 代码块
  ├── ArXiv 论文    → PDF → text → 按章节切片
  └── 网页/博客     → html2text → 按段落切片
  │
  ▼
文本清洗 (去噪声、统一格式)
  │
  ▼
Chunk 切片 (500-1000字符, overlap 150)
  │
  ▼
Embedding (DeepSeek API)
  │
  ▼
ChromaDB 存储
```

### 5.2 数据模型

```python
# ChromaDB metadata schema
{
    "doc_id": "hikyuu/factor.md#section-3",
    "source": "hikyuu官方文档",
    "category": "金融量化/框架文档",
    "sub_category": "因子管理",
    "file_path": "/path/to/factor.md",
    "chunk_id": 0,
    "chunk_total": 15,
    "title": "Factor 类",
    "language": "zh",
    "code_blocks": ["Factor(name, formula, ktype=...)"],
    "created_at": "2026-05-26",
    "updated_at": "2026-05-26",
    "tags": ["因子", "Factor", "API"],
}
```

### 5.3 检索增强

```
用户查询 → Query 重写 (可选) → Embedding → Top-K (MMR)
    │
    ▼
粗排 (向量相似度) → Top 20
    │
    ▼
精排 (可选: Cross-encoder 或 LLM rerank) → Top 5
    │
    ▼
拼接 Prompt → 生成回答
```

## 六、质量标准

### 内容入库检查清单

- [ ] 是否有明确的来源和日期？
- [ ] 代码示例是否完整可运行？
- [ ] 是否有中文说明（关键概念）？
- [ ] 是否避免重复（同一知识点不应有多个相似片段）？
- [ ] 是否有分类标签？

### 检索效果评估

- 准确率：Top-5 中至少有 1 条直接相关
- 完整性：回答覆盖问题的所有关键点
- 去幻觉：无中生有的内容比例应趋近于 0

## 七、里程碑（含交付物 + 价值）

### M1 — hikyuu 文档入库

| 维度 | 说明 |
|------|------|
| **内容** | factor.md + README + 14 个 Jupyter Notebook → 文本切片 → 向量化 |
| **预计** | 1 天 |

#### 交付物

| 交付物 | 路径 | 说明 |
|--------|------|------|
| ChromaDB 实例 | `~/.rag-hikyuu/chroma.sqlite3` | 向量数据库，持久化存储 |
| 构建脚本 | `rag/build_index.py` | 文档 → 切片 → Embedding → 入库，一键执行 |
| 检索库 | `rag/search.py` | `search("动量因子", top_k=5)` → 返回相关片段列表 |
| CLI 工具 | `rag/cli.py` | `python -m rag search "xxx"` 命令行检索 |
| 索引报告 | `rag/INDEX_REPORT.md` | 入库统计：文档数、chunk数、每文档切片明细 |

#### 价值

| 能做的 | 不能做的 |
|--------|---------|
| ✅ 查 hikyuu API，秒出结果 | ❌ 不能在对话中自然触发（M3 做） |
| ✅ 不翻本地文件夹找文档 | ❌ 知识域仅限 hikyuu |
| ✅ 代码片段可直接复制 | ❌ 检索质量待迭代优化 |
| ✅ 后续加内容跑脚本即可 |
